HOMEPAGE BANNER PHOTOS
======================
1. Copy your photos into THIS folder (JPEG, PNG, WebP or AVIF, any size).
2. In the terminal, from the project folder, run:   npm run hero-images
3. Restart:   npm run dev

Tips
- Up to 6 photos are used. They fade into each other every few seconds.
- Wide (landscape) photos work best. Faces near the middle or right look good.
- Use photos ESWA owns or has permission to use. Free-to-use stock sites
  (Unsplash, Pexels) are fine, but check each photo's licence.
- For photos of real children, make sure there is a permission on file.
- To remove a photo: delete it from this folder and run the command again.
- No photos? The banner still shows soft moving shapes.
